# 鳴潮（Wuthering Waves） ローテーション作成ツール

鳴潮（Wuthering Waves）のパーティ編成におけるローテーションシートを作成し、画像（PNG）として保存・共有できるWebツールです。

## 🚀 公開ページ
👉 [鳴潮 ローテーション作成ツールを開く](https://blair0613.github.io/wuwa-rotation-maker/)

---

## ✨ 主な機能

- **直感的なローテ編集**
  - キャラクターとモーションを選択するだけで簡単にローテーションを作成可能。
  - 同一キャラクターが連続する場合は自動でまとめ表示。
  - ドラッグ＆ドロップによるアクションの順番入れ替え・個別に削除可能。
  - 「開幕ローテ」「ループローテ」の編集モード切り替え機能。
- **動的サイズ調整付きプレビュー**
  - アクション数（改行数）に応じてキャンバスの高さが自動調整されるため、溢れや重なりが発生しません。
- **ワンクリック画像出力**
  - 作成したローテーションを PNG 画像としてダウンロード可能。

---

## 🛠️ 使用技術

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **HTML5 Canvas API**

---

## 📖 使い方

1. 編集したい対象（**開幕ローテ** または **ループローテ**）の「編集する」ボタンをクリックして「編集中...」の状態にします。
2. キャラクター一覧から使用するキャラクターを選択します。
3. モーション一覧から繰り出すアクションをクリックして追加します。
4. 下部のプレビューを確認し、問題がなければ **「PNGとして保存」** ボタンを押して画像をダウンロードします。
